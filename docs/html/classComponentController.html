Detailed Description

Concrete Subject. Holds a non-owning list of Observers and pushes Notice values to them via notify().

Note
Design decision (ownership): ComponentController stores raw, non-owning Observer* pointers. It never calls delete on anything in observerList, including in its own destructor. Whatever owns a given Observer (typically an EventComponent Leaf owned by the Composite tree) is responsible for calling detach() on every controller it registered with before that observer is destroyed, to avoid dangling pointers.
